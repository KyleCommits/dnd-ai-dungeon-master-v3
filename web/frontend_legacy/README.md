# Legacy React Wood UI (Deprecated)

This is the previous CRA/React wood-theme client. It is **not** started by `python start_web_system.py`.

Primary UI is the ASCII browser terminal at `http://localhost:8080/` (served from `web/ascii_client`).

To run this legacy UI manually for reference:

```text
cd web/frontend_legacy
npm install
npm start
```

It expects the API at `http://localhost:8080`.
